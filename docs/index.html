      書架

        書存在這支手機的瀏覽器裡，不會上傳給別人。清除瀏覽資料後要重新加入。（在 Claude 網頁裡打開時，還會備份到你的 Claude 帳號。）

        文字顏色

        朗讀

        語速
        聲音清單來自你的手機系統。

        翻譯

        選取文字時自動翻譯

        長按一個單字，或拖曳選取一句話，下方就會出現翻譯。中文介面會把英文翻成中文，英文介面會把中文翻成英文。

        一直往下滑就能讀完整本書。往下讀時工具列會自動收起，往上滑一點或點一下文字就會出現。閱讀位置會自動記住。

        聽書時，從畫面上第一段開始念，畫面會跟著捲動。朗讀中點任何一段，就會改從那段開始念。手機螢幕關掉後，有些瀏覽器會停止朗讀。
